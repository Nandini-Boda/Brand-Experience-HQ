# Data Dictionary
## Hospitality Weekly Insight Hub

### 1. Purpose

This document describes the main business data categories used across Hospitality Weekly Insight Hub.

It provides a reference for understanding the information presented in the dashboard and how it supports hospitality performance reporting.

The descriptions below represent logical business data categories, not exact database table or column names.

### 2. Revenue Reporting

| Data Category | Description | Reporting Purpose |
|---|---|---|
| F&B Sales | Food and beverage sales information | Monitor sales performance |
| Revenue Targets | Planned sales and revenue targets | Compare actual performance against targets |
| Item Sales | Individual product or menu-item sales | Understand item-level performance |
| Sales Bookings | Sales-related booking information | Review booking performance |
| Upselling Performance | Information on additional sales and upselling | Monitor upselling activity |
| Upselling Targets | Planned upselling targets | Compare upselling results with targets |

### 3. Brand & Guest Experience

| Data Category | Description | Reporting Purpose |
|---|---|---|
| Guest Ratings | Guest rating information | Monitor guest satisfaction indicators |
| Guest Reviews | Guest feedback and review information | Understand guest experience trends |

### 4. People Analytics

| Data Category | Description | Reporting Purpose |
|---|---|---|
| Workforce Information | Employee and workforce-related reporting information | Review workforce metrics |
| Training Attendance | Employee training participation information | Monitor training attendance and learning activity |

### 5. Property Performance

| Data Category | Description | Reporting Purpose |
|---|---|---|
| Guest Complaints | Guest complaint and feedback information | Identify operational concerns |
| Property Information | Property-related reporting context | Support property-level performance review |

### 6. Executive Review

| Data Category | Description | Reporting Purpose |
|---|---|---|
| Executive Discussion Items | Management discussion points and review topics | Organize management discussions |
| Follow-up Information | Status and tracking information associated with discussion items | Support action monitoring |

### 7. Data Usage

The reporting categories support the dashboard's five business perspectives:

- Revenue reporting
- Brand and guest experience reporting
- People analytics
- Property performance monitoring
- Executive review and follow-up

### 8. Important Notes

- Business category names in this document are generalized descriptions.
- They should not be interpreted as exact database table or column names.
- The document does not publish internal project identifiers or private database structures.
- Public portfolio examples must use approved demonstration or sanitized information.
- No guest or employee personal information should be included in public documentation.
